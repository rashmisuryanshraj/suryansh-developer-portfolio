# Suryansh Raj — Developer Portfolio

## Run locally
1. Extract this ZIP.
2. Open the `suryansh-developer-portfolio` folder in VS Code.
3. Open `index.html` with the Live Server extension, or copy the folder into XAMPP's `htdocs` and visit `http://localhost/suryansh-developer-portfolio/`.
